# 台股五因子研究：因子變體選擇與 LGBM 合成

以台股 2009 到 2026 年資料，檢驗兩個問題：

1. **因子變體選擇**：在樣本內（IS）挑出表現較好的因子變體，能否改善樣本外（OOS）的策略績效？
2. **因子合成方式**：用 LightGBM（LGBM）合成因子，能否勝過簡單的等權合成（EW）？

研究規則與預期在打開 OOS 資料前事先登錄，OOS 只執行一次。

## 結論

- **兩個問題的答案都是「沒有偵測到顯著差異」**，4 組 OOS 比較的 95% 信賴區間都包含 0。
- **沒有勝者選擇過度擬合的證據**：winner-EW 在 IS 沒有勝過 v0-EW，在 OOS 反而略好。
- **策略絕對表現強，但相對大盤大致持平**：OOS 年化報酬 20.7%–23.4%、Sharpe 1.30–1.53，大盤 TRTEJ 同期為 21.3%、1.13。選股優勢仍為正，但等權股票池在 OOS 落後大盤，兩者幾乎抵銷。
- **較簡單的等權合成在開發與維護成本上較有優勢**：5 因子合成時，LGBM 與等權的差異不顯著。

| OOS（2017-11 到 2026-08） | v0-EW | winner-EW | v0-LGBM | winner-LGBM | 股票池等權 | TRTEJ |
|---|---|---|---|---|---|---|
| 年化報酬 | 20.7% | 23.4% | 23.2% | 23.0% | 14.6% | 21.3% |
| Sharpe | 1.30 | 1.53 | 1.49 | 1.53 | 0.86 | 1.13 |
| 最大回撤 | −29.5% | −29.3% | −26.1% | −25.6% | −32.4% | −29.6% |

## Pipeline 設計

![TW 5 Factor Lab](img/tw-5-factor-lab.png)

| 項目 | 設定 |
|---|---|
| 資料 | TEJ TQuant Lab，4 張資料表，2005-01-03 到 2026-09-24 |
| 股票池 | 上市櫃普通股，排除金融業，每期市值前 50%（約 575–850 檔） |
| 換股 | 季頻，財報法定期限（03/31、05/15、08/14、11/14）後的第一個交易日 |
| 樣本切分 | 暖機期 2006-04 到 2009-04；IS 2009-05 到 2017-08（34 期）；OOS 2017-11 到 2026-05（35 期） |
| 因子 | 5 個領域（獲利、價值、動能、風險、規模），每領域 v0、v1 兩個變體 |
| 策略 | 只做多，買進綜合排名前 2%、跌出前 10% 賣出，持股等權 |
| 成本 | 手續費 0.1425%（雙邊）、證交稅 0.3%（賣出）、滑價 0.1%（雙邊） |
| 前視偏誤控制 | 財報依實際公告日取用；LGBM 以 walk-forward 擴張窗口訓練，訓練與預測間隔 2 期 |

## 名詞

| 名詞 | 說明 |
|---|---|
| IS／OOS | 樣本內／樣本外 |
| v0／v1 | 每個領域事先定義的基礎變體／本專案提出的優化變體 |
| winner | 依 IS 十分位 LS 在每個領域選出的勝者（A0、B1、C0、D1、E1） |
| LS | 第 10 組減第 1 組的每期平均報酬 |
| 股票池等權 | 等權持有整個股票池，用來衡量選股本身的貢獻 |
| TRTEJ | TEJ 台股含息報酬指數，作為大盤基準 |

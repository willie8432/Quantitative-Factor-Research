# Backtesting 回測結果報告

## 1. Overview

4 個策略（v0-EW、winner-EW、v0-LGBM、winner-LGBM）和兩個參照基準（股票池等權、大盤），以 IS、OOS 做策略績效回測以及解讀。

### Conclusion

- 因子變體的選擇與合成方式，樣本外回測結果不顯著。
- 沒有因子勝者選擇過度擬合的證據。winner-EW 在 IS 沒有勝過 v0-EW，在 OOS 反而略好。
- **策略的絕對表現強，但 OOS 期間相對大盤只是大致持平**。等權股票池落後大盤導致選股優勢不顯著。推論，OOS 期間大盤受少數大型權值股推升。
- 只做多的策略仍會隨市場系統性風險而下跌。 4 個策略的最大回撤都發生在 2020 年 3 月的疫情急跌。
- 單因子檢定的勝負延續，除了大市值因子（E0）轉強，但沒有轉化為策略層級的優勢。

## 2. Backtesting Design

### 2.1 Backtesting Setting

| 項目 | 設定 |
|---|---|
| 因子 | 5 個領域（獲利、價值、動能、風險、規模） |
| v0／winner | v0：每個領域事先定義的變體；winner：依 IS 單因子表現選出的變體 |
| 合成策略 | EW：等權重合成；LGBM：LightGBM 預測模型 |
| 樣本內（IS） | 2009-05 到 2017-08（34 期） |
| 樣本外（OOS） | 2017-11 到 2026-08（35 期） |
| 操作方式 | 做多操作 |
| 買入操作 | 買進排名前 2%，持股等權 |
| 賣出操作 | 賣出跌出前 10% |
| 換股頻率（Rebalance time） | 季頻，財報法定期限（03/31、05/15、08/14、11/14）後的第一個交易日 |
| 成本 | 手續費 0.1425%（雙邊）、證交稅 0.3%（賣出）、滑價 0.1%（雙邊） |
| 基準 | TRTEJ（含息報酬指數）；另以股票池等權組合作為參照 |
> OOS 到 2026-05 為最後換股日；2026-08 為最後一期持有結束日，記錄最後一期報酬

### 2.2 策略說明 

| 策略 | 因子 | 合成 | IS 實驗 | OOS 實驗 | 
|---|---|---|---|---|
| v0-EW | A0、B0、C0、D0、E0 | 1/5 等權相加 | 回測 | 回測 |
| winner-EW | A0、B1、C0、D1、E1 | 1/5 等權相加 | 回測 | 回測 |
| v0-LGBM | A0、B0、C0、D0、E0 | LGBM | （訓練、不回測） | （每年 walk-forward 訓練）、回測 |
| winner-LGBM | A0、B1、C0、D1、E1 | LGBM | （訓練、不回測） | （每年 walk-forward 訓練）、回測 |

### 2.3 LGBM 設定

超參數在訓練前事先固定，不做調參，全部訓練共用同一組設定。

#### Hyperparameter
| 參數 | 值 | 說明 |
|---|---|---|
| objective | regression（L2） | 預測下期報酬的百分位排名 |
| learning_rate | 0.05 | 每棵樹的修正幅度 |
| num_iterations | 2000 | 樹數上限；實際樹數由 early stopping 決定 |
| early_stopping_round | 100 | 驗證集連續 100 輪沒有改善即停止 |
| max_depth | 3 | 淺樹，降低過度擬合 |
| num_leaves | 8 | 每棵樹最多 8 片葉 |
| min_data_in_leaf | 200 | 每片葉子至少 200 筆，避免學到個股雜訊 |

> 不使用 L1、L2 正則化，不做特徵或資料抽樣，固定種子以確保結果可重現。

#### Training

| 項目 | 設定 |
|---|---|
| 特徵 | 5 個因子的百分位排名 |
| 標籤 | 下期報酬在股票池內的百分位排名 |
| 訓練方式 | walk-forward，擴張窗口；每次從頭訓練 |
| 重新訓練 | 每年第一次換股（4 月） |
| 首次訓練 | 2017-11，使用 IS 的 33 期 |
| 訓練與預測的間隔 | 2 期（預測第 T 期時，使用的最新訓練期為 T−2） |
| 樹數決定 | 以訓練窗口最後 4 期作為驗證集，用 early stopping 決定樹數；再以全部訓練資料、相同樹數重新訓練 |


```
💡 避免報酬標籤前視偏誤

在第 T 期（換股日 T_d）：
- 訓練可用期數：第一期到第 T−2 期。第 T−1 期的報酬要到 T_d 收盤才確定，而決策必須在 T_d 收盤前完成，所以無法參與訓練。
- 輸入因子：第 T 期的因子，使用 T_d−1 以前的資料（與等權合成相同）。
- 預測目標：第 T 期的報酬，從 T_d 收盤到 (T+1)_d 收盤。
- 最新訓練期與預測期的差距：2–5 期。模型每年只重新訓練一次，剛重訓時差 2 期，到下次重訓前差 5 期。
```

#### 解讀
- 2018 到 2024 年中，策略主要領先，資金累積速度持續高於股票池等權與 TRTEJ。
- 2024 年中以後，TRTEJ 則大幅上升，而策略大致持平。TRTEJ 在 OOS 最後一年追上 v0-EW 策略。這與超額報酬拆解的結論一致：OOS 中，策略相對大盤的優勢縮小，主要來自大盤變強（TRTEJ 黑色細線大幅上升）。

<p align="center">
  <img src="img/oos_drawdown.png" alt="OOS 回撤" width="1000">
</p>

#### 解讀
- 策略的最大回撤都發生在 2020 年 3 月的疫情急跌，深度 25.6%–29.5%。說明只做多的策略無法避開市場的系統性風險。
- 股票池等權與大盤的最大回撤發生在其他時期：股票池等權的最大回撤在 2025 年的急跌；TRTEJ 的最大回撤在 2022 年的空頭。
  - 推論：2022 年的大型科技股下跌較深。股票池等權以等權持有約 700 檔股票，大型科技股的比重遠低於大盤，降低了單一個股的影響；策略依獲利、價值、低波動等因子選股，這類股票在升息造成的空頭中通常較抗跌。
  - 推論：2024 年中以後同樣的，因為這兩者大型科技股的比重較低，在 2024 年中以後由大型科技股推升的台股多頭中，策略與股票池都跟不上大盤的漲勢。
- 策略自 2024 年中的高點以後，到 OOS 結束時仍未創新高 (除了 v0-EW)。而 TRTEJ 在同一時期回到高點、屢創新高。這是策略近期表現落後大盤的另一個角度。

```
💡 市場事件

- 2018-10：美國升息與美中貿易戰，引發全球股市下跌。各序列回撤約 10%–20%。
- 2020-01 到 2020-03：新冠疫情引發全球股災。四個策略的最大回撤 25.6%–29.5%。
- 2022-01 到 2022-10：美國聯準會快速升息、俄烏戰爭。台股全年空頭，TRTEJ 的最大回撤 29.6%。
- 2025-04：美國宣布對等關稅之後。股票池等權在這段期間的最大回撤是 32.4%。
```

### 3.4 IS vs OOS 每期超額報酬拆解

拆解方式：
- **`策略優勢`**（每期超額報酬）= 策略 − 大盤
- **`選股優勢`** = 策略 − 股票池等權
- `策略優勢` = `選股優勢` +（股票池等權 − 大盤）
- IS（34 期）每期報酬：股票池等權 = 2.47%；大盤 = 2.56%；股票池等權 − 大盤 = -0.09%
- OOS（35 期）每期報酬：股票池等權 = 3.88%；大盤 = 5.38%；股票池等權 − 大盤 = -1.50%

| 策略（每期報酬） | 期間 | 策略優勢 | 選股優勢 |
|---|---|---|---|
| v0-EW（5.68%） | IS |  3.12% | 3.21% | 
| winner-EW（5.58%） | IS |  3.01% | 3.11% | 
| v0-EW（5.23%） | OOS |  −0.16% | 1.35% | 
| winner-EW（5.84%） | OOS |  0.46% | 1.96% | 
| v0-LGBM（5.74%） | OOS |  0.36% | 1.86% | 
| winner-LGBM（5.69%） | OOS |  0.31% | 1.81% | 
> 大盤指的是指數報酬（TRTEJ）；上表皆為每期平均報酬（每期約一季）

#### 解讀
- 策略本身的報酬在 OOS 沒有明顯下降。兩個 EW 策略每期報酬從 IS 的 5.68%、5.58%，變為 OOS 的 5.23%、5.84%。
- 選股優勢從每期約 3% 縮小到 1.35%–1.96%，後續統計說明 OOS 多數因子的 IC 仍為正但轉弱。進一步分析請看 [3.5 OOS 單因子檢定](#35-oos-單因子檢定) 與 [3.6 累積 Rank IC](#36-累積-rank-ic)。
- OOS 大盤強勢。大盤的每期報酬在 OOS 約增加為兩倍（TRTEJ 從 2.56% 升到 5.38%）。而股票池等權只從 2.47% 升到 3.88%，OOS 每期落後大盤 1.50%。
- 策略優勢的縮小，約一半來自選股優勢減弱、約一半來自股票池落後大盤。以 IS 到 OOS 的每期變化計算：
  - v0-EW 的策略優勢減少 3.28 百分點 = 選股優勢減少 1.86 (約 57%) + 股票池相對大盤減少 1.41 (約 43%)
  - winner-EW 的策略優勢減少 2.55 百分點 = 選股優勢減少 1.15 (約 45%) + 股票池相對大盤減少 1.41 (約 55%)
- 推論，未經驗證：OOS 期間大盤受少數超大型權值股推升，等權的股票池跟不上；這與後續觀察規模因子反轉（大型股較佳）的方向一致。

### 3.5 OOS 單因子檢定

#### 因子勝者是否延續到樣本外

| 領域 | v0 / v1 IC | v0 / v1 LS | LS 勝者 |
|---|---|---|---|
| 獲利 | 0.065 / 0.031 | 2.97% / 0.07% | **A0** |
| 價值 | 0.050 / 0.089 | −0.54% / 1.37% | **B1** |
| 動能 | 0.047 / 0.001 | 3.86% / 2.23% | **C0** |
| 風險 | 0.035 / 0.102 | −4.71% / −2.17% | **D1** |
| 規模 | 0.023 / −0.023 | 2.12% / −2.12% | **E0** |

#### 解讀
- 5 個領域中有 4 個因子勝者延續到 OOS。規模的反轉（大型股較佳）不顯著，且規模因子在 OOS 期間依然沒有產生足夠的預測力。
- D1 依然勝過 D0，顯示低波動度的預測能力依然勝過低 beta。雖然兩者 LS 都為負，但是都不顯著（t_D0 = −1.60、t_D1 = −0.90）。推論，可能與市場曝險有關，OOS 的市場強勢多頭（股票池等權年化 14.6%），造成高波動的股票漲得較多。
- 不過，單因子層級的勝負延續，並沒有轉化為策略層級的優勢。winner-EW 每期比 v0-EW 超額 +0.61%（問題一不顯著）。

### 3.6 累積 Rank IC
<p align="center">
  <img src="img/cumulative_ic.png" alt="累積 Rank IC" width="1200">
</p>

#### 解讀
- 多數因子在 OOS 仍有正的預測能力。獲利（A0）、價值（B1）、動能（C0）、風險（D1）等勝者因子，累積 IC 在 OOS 持續上升，但是斜率大多比 IS 平緩。與平均 IC 的比較一致。
- B0 的斜率在 OOS 變陡，PB 出現微弱預測力。
- C1 在兩個期間都幾乎持平，幾乎沒有預測力。
- E0、E1 規模因子在 IS 沒有方向，OOS 轉為大型股較佳。
- **2025 到 2026 年多個因子同時轉弱**（由圖觀察）：殘差 PB（B1）、低 beta（D0）、低波動度（D1）的累積 IC 轉為下降，規模往大型股方向加速。推論，未經驗證：這段期間由大型科技股主導，與價值、低風險、小型股方向相反。這與策略在 2024 年中以後資金累積持平、股票池落後大盤的時間點一致。
